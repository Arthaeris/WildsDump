Searching

Search is not case-sensitive, and every word you type must appear somewhere in the entry, in any order.

ancient potion
Entries containing both "ancient" and "potion".
"ancient potion"
Quotes search for that exact phrase.

Search operators

Type an operator, a colon, and a value to search one field only. Use quotes for values with spaces, e.g. name:"great sword". Operators can be combined.

name:
Only the entry's name or title.
npc: or speaker:
The NPC who speaks the line (or their dialogue ID).
dialogue:
Text that appears in dialogue entries only.
category:
The category, e.g. category:items.
file:
The source file name, e.g. file:npc001.
family:
The file family, e.g. family:item.
id:
The entry's ID number.

Example: npc:guildmarm quest finds lines spoken by the Guildmarm that mention "quest".

Jumping between matches

While searching, use the ▲ ▼ buttons next to the result count (or in the floating search button) to jump from one highlighted word to the next. On a keyboard, press Enter for the next match and Shift + Enter for the previous one.

The numbers on the Type filters show how many results each category has for your current search.

Other tips

Switch game
Tap the big title at the top to cycle through the games.
Floating search
After scrolling down, tap the round search button at the bottom right to search from anywhere.
Share a link
The address bar always reflects the current game, search and page, so you can copy it to share or bookmark exactly what you see. The browser's back gesture moves between pages.
Format
IDs shows entry IDs in the text, Clean hides them, and Code shows it as a code block, ready to paste.
JP
Switches a card to the Japanese text, where available.
